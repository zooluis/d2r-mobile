# D2R Mobile

**一個面向《暗黑破壞神 II：獄火重生》術士君臨資料片的開源 iOS / macOS 相容層。** 它把你購買的任天堂 Switch 版本（含資料片）完整地帶到 iPhone、iPad 和 Mac：原始遊戲程式碼原生執行，每個控制都為觸控重建，幀率穩定在 60 fps，從主選單一秒後你就能進入遊戲。現在還有一個原生 macOS 版本（首個版本）：在 Apple 晶片 Mac 上雙擊啟動，並支援鍵盤、滑鼠和手把。Apple TV 4K（第三代，A15）有一個社群移植版（開發者預覽），目前只在其作者裝置上到達了角色選擇畫面；見下面的裝置表。

這不是一個「勉強能跑」的技術示範。它是一個為日常遊玩打磨的行動版，從你第一個角色一直到遊戲後期全程可用。

平台：iPhone / iPad（iOS 26 及更新；iOS 18 – 25 用舊 API 建置）· Mac（Apple 晶片，macOS 26 或更新；macOS 15 – 25 用舊 API 建置）· Apple TV 4K（第三代，A15；社群移植版，開發者預覽）· 遊戲版本：帶術士君臨的 Switch 版，1.0.34.0（對應 PC 版 3.3.94012）· 英語 / 中文 / Español / Русский · 授權條款：MIT · **自帶遊戲檔案**

## 它是什麼，不是什麼

**它是：**

- 遊戲自己的 aarch64 程式，**直接在裝置上執行**，沒有模擬 CPU。iPhone 和 Switch 使用同一類處理器；只有少數幾條在 Apple 核心下無法原樣執行的指令被重寫，程式其餘每個位元組都保持原樣出貨。每個職業、每條符文之語、恐怖地帶、Boss、掉落規則和任務流程都與原作完全一致。
- 遊戲期望的平台服務——系統呼叫、檔案系統、圖形 API、音訊、輸入——由一個為 Apple 平台編寫的小型宿主提供。圖形 API 完全用 Apple 的 Metal 重新實作，中間沒有模擬層，著色器從遊戲原作離線翻譯。
- 一個為手機打造的移植，並做到了極致：完整的觸控方案、無邊框 iPhone 和真正的全螢幕 iPad 顯示、手把支援、省電模式、存檔同步、中英文，以及原作從未有的一整套後期模式和生活品質功能。

**它不是：**

- 模擬器、雲遊戲或串流。
- **遊戲內容來源。它不含也不分發任何內容。** 本倉庫沒有遊戲程式、美術、文字、資料表或著色器；所有這些都是在你自己的機器上從你自己的檔案生成的（見 [docs/GAME_FILES.md](docs/GAME_FILES.md)）。倉庫帶的是我們記錄下來的使移植生效的介面資訊——著色器介面描述、圖形 API 函式表、程式內位址等——在 [docs/DERIVED.md](docs/DERIVED.md) 中逐項列出。
- 線上。沒有多人遊戲；遊戲完全離線執行，無需線上帳號。

## 久經考驗

封閉測試中全部 **44** 台 iPhone 和 iPad——35 台註冊直裝的裝置（25 台 iPhone 和 10 台 iPad），外加 9 個各帶一台裝置的 TestFlight 帳號——**用多個角色完成了普通、噩夢和地獄**，體驗極佳。從 6 GB 記憶體的 iPhone 14 Pro Max 到最新的 iPad Pro，沒有一台裝置掉隊。測試過的最低型號為 **iPhone 14 Pro Max（A16，6 GB）：完美的 60 fps**。iPhone 和 iPad 共用一個安裝包。

## 快速、流暢、省電

在真實裝置（iPhone 17 Pro Max）上測得：遊戲內幀率 **60 fps** 穩定不掉幀；應用程式啟動 0.15 s；到主選單約 1 s；從主選單進入遊戲**約 1 s**；快速重啟回到遊戲約 1.2 s；換幕最長幀約 0.1 s；60 fps 全機功耗**約 3.8 W**（營地，50% 亮度）：滿電可持續遊玩近 5 小時；30 fps 省電模式**約 1.85 W**，約為 60 fps 的一半，續航約兩倍。

安裝包僅 100 MB 出頭。遊戲資源（約 5.6 GB）單獨放到手機，更新應用程式不會碰到你的存檔或資源。

為什麼這麼快：程式原生執行，沒有一條指令經過模擬；圖形直連 Metal；每個著色器都離線翻譯並提前編譯，進入新場景時無需編譯。較老晶片（A16 及更早，如 iPhone 14 系列和 iPhone 15）不支援遊戲原始的壓縮紋理格式；它們需要從你自己的遊戲檔案製作額外的紋理包，然後也能跑滿幀率——見 [docs/LEGACY_DEVICES.md](docs/LEGACY_DEVICES.md)。

## 為手指重新設計

這不是把手把貼到螢幕上。每個面板和每個動作都在一個設計原則下為手指重建：**保持原始介面語言，用手勢而不是往螢幕上加按鈕**。文字大小和點擊目標按手指尺寸設計。你拿起就會玩，長時間遊玩也舒適。

- **移動**：帶精確對角線的虛擬搖桿；點擊 NPC 或地面可自動尋路；門、傳送門和洞穴入口整面可點。
- **戰鬥**：按技能按鈕施放，按住持續施放，**拖動以任意角度瞄準**；附近怪物自動鎖定。兩套技能。副武器技能一鍵施放——遊戲自動換武器、施放、換回——按鈕顯示剩餘充能。
- **Boss 血條**：固定在螢幕頂部，顯示剩餘百分比。
- **物品**：點擊、雙擊、長按和拖放都跟手。雙擊裝備可裝備/卸下；把物品拖到商人面板任意處出售；堆疊上雙擊取 1、長按取 3；長按空格整理。
- **文字**：用系統鍵盤輸入。角色名可以是中文；留空則隨機產生。
- **螢幕**：iPhone 上 19.5:9 螢幕無邊填充，避開瀏海和圓角；iPad 上遊戲鋪滿整個螢幕，開啟面板時介面自動置中；3D 畫面可調亮。

### 手把

連接手把並按下任意鍵：介面切換為原始手把配置，每個面板底部顯示按鍵提示。觸屏立即切回觸控介面。物品欄、倉庫、技能樹、編年史和設定都可用手把完全導覽，按鍵對應與 Switch 一致。

## 在原作之上的新玩法

通關原作只是開始。在不改動原始規則的前提下，我們加入了一整套讓你持續刷刷刷的後期內容。

### 大秘境

地獄通關後從哈洛加斯的紅門進入。共 100 層，怪物逐層變強；在 15 分鐘內填滿進度條並擊殺秘境守衛即可通關。每通關 2 層 +1 技能點 +5 屬性點，技能等級上限從 20 提到 40。每 10 層有首通獎勵，通關 10 層為傭兵解鎖 6 個新裝備槽。

### 後期 Boss Rush、極樂世界模式和擊殺榜

- **後期 Boss Rush**：地獄通關後解鎖，共 12 關；第 11 關是暗黑破壞神複製體，第 12 關是三大 Uber Boss。
- **極樂世界模式**（建角色時選擇）：獨特 ×5、套裝 ×3、符文 ×5；「不掉落」機率降到十分之一，Boss 每次擊殺都像首殺一樣掉落。
- **擊殺榜**：每個 Boss 的擊殺數、首殺時間、掉落的獨特和套裝物品數，以及最佳和平均擊殺時間。

### 儲存：收藏家的樂園

- **編年史倉庫**：每件已鑑定的獨特和套裝物品有固定槽位，全角色共用，可搜尋，可存取；「存入」按鈕一鍵把背包和赫拉迪克方塊中的獨特、套裝物品存入。
- **倉庫**：擴寬到 14 欄，5 頁個人 + 5 頁共用。
- **藏寶閣**：寶石、符文和材料頁合併為一頁，中間是赫拉迪克方塊的合成格，找東西和合成不再翻頁。
- **荷包**：擴充背包。野外拾得的符文和寶石自動放入，不佔背包空間。

## 工作原理

程式重寫器（`dm/tools/patch_nso.py`）只重寫少數幾條無法在 Apple 核心下原樣執行的指令（執行緒指標暫存器、系統呼叫、計時器），其餘逐位元組保持原樣；宿主（`dm/host`）載入重寫後的程式並提供它呼叫的平台服務；圖形層（`dm/gfx`）在 Metal 上實作遊戲圖形 API，著色器從原作離線翻譯；iOS 應用程式（`dm/ios`）是外殼、觸控和介面；驗證（`dm/verify`）檢查重寫後的程式碼與原作行為完全一致，加上每次改動都要通過的迴歸門。

**為什麼可以信任它：** 穩定性不是運氣。測試和驗證工具是專案的一部分——宿主和圖形層的單元測試、每條重寫指令的等價性檢查、觸控介面的指令碼化通關迴歸，以及裝置冒煙測試。

## 開始使用

兩條路徑都從**你購買的遊戲檔案**開始：Switch 版的《暗黑破壞神 II：獄火重生》加術士君臨資料片，更新到 1.0.34.0。準備工作見 [docs/GAME_FILES.md](docs/GAME_FILES.md)。

> 本專案只提供工具和一個不含遊戲內容的外殼。我們不分發、不背書、也不對任何第三方分發遊戲資源、遊戲可執行檔或含遊戲內容的安裝包負責。請只使用你合法擁有的遊戲檔案。

| | 有 Mac | 無 Mac |
|---|---|---|
| 電腦 | 裝了 Xcode 的 Apple 晶片 Mac | Windows / Linux / 沒有 Xcode 的 Mac |
| 方式 | 從原始碼完整建置 | 下載不含遊戲內容的「外殼」，用打包工具加入你自己的遊戲內容，再用側載工具安裝 |
| 說明 | 下面三步 | [docs/NO_XCODE.md](docs/NO_XCODE.md) |

簽名用的 Apple 帳號：付費開發者帳號給你全部功能；免費 Apple ID 也行（無 iCloud 存檔同步，且應用程式需每 7 天重新簽名重裝）。相依完整清單見 [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md)。

### 有 Mac：三步

1. 把遊戲檔案放進工作區（預設 `~/dm-work`，或設定 `DM_ROOT`）。
2. 準備工作區（`./setup.sh`）：檢查工具、重寫遊戲程式、把遊戲著色器翻譯到 Metal。首次執行較久。
3. 填寫簽名資訊並建置應用程式（`cp dm/ios/local.env.example dm/ios/local.env`，設定 `DM_TEAM_ID` 和 `DM_BUNDLE_ID`；免費 Apple ID 還需 `DM_FREE_ACCOUNT=1` 和 `DM_IOS_UDID`；然後 `cd dm/ios && ./run.sh build`）。

首次在手機開啟應用程式時，它會要求「遊戲資源資料夾」——你遊戲檔案中的 18 個資源封存。`./setup.sh check` 是健康檢查。

### 直接在 Mac 上玩

同樣 `./setup.sh` 後，再一條指令即可建置原生 macOS App（`source ~/dm-work/build/cache/dm/venv/bin/activate && dm/tools/mac_app.sh`），雙擊啟動，支援鍵盤、滑鼠和手把，無需開發者帳號。

### 無 Mac：外殼 + 打包工具

從本倉庫 [Releases 頁面](https://github.com/jhaizhou-ops/d2r-mobile/releases)下載預建置的「外殼」包（不含遊戲內容），加入你自己的遊戲檔案，在 Windows 或 Linux 上製作安裝包，再用側載工具簽名安裝。這條路徑上，因為製作包的電腦沒有 Apple 著色器編譯器，手機**首次啟動**會花約 7 分鐘編譯著色器（一次性，有進度條）。步驟和驗證程度見 [docs/NO_XCODE.md](docs/NO_XCODE.md)。

## 已知限制

## 貢獻與回饋

- 遇到問題就開 Issue（有範本）；附上暫停選單中「Share Diagnostics」匯出的檔案最有幫助。
- 對標記未驗證的項，告訴我們成功與否。兩個答案都有價值。
- 改程式碼：先讓上面的測試入口通過。每次改動都必須通過迴歸門。

**把它帶到其他平台：** 這種方法不限於 iPhone 和 iPad。Apple 晶片 Mac 已有原生版，Apple TV 有社群移植版。Android 手機使用同類處理器，遊戲程式也能原生執行，路徑完全開放：只需替換宿主和圖形層面向平台的部分。作者手邊沒有 Android 手機，很希望有人把它帶到 Android。

**把它帶到其他遊戲：** 已經有人在同一宿主上試過其他 Switch 遊戲。宿主有些預設為 iOS 開啟且為這個遊戲寫的預設行為，換別的遊戲會先撞上這些，開始前先關掉或移走（見原 README 列出的 `dm/host/*.c` 檔案）。更乾淨的安排是把這些預設行為移到按遊戲設定，讓宿主保持無遊戲特定預設值；歡迎朝這個方向的拉取請求。
