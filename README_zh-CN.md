# D2R Mobile

**一个面向《暗黑破坏神 II：狱火重生》术士君临资料片的开源 iOS / macOS 兼容层。** 它把你购买的任天堂 Switch 版本（含资料片）完整地带到 iPhone、iPad 和 Mac：原始游戏代码原生运行，每个控制都为触控重建，帧率稳定在 60 fps，从主菜单一秒后你就能进入游戏。现在还有一个原生 macOS 版本（首个版本）：在 Apple 芯片 Mac 上双击启动，并支持键盘、鼠标和手柄。Apple TV 4K（第三代，A15）有一个社区移植版（开发者预览），目前只在其作者设备上到达了角色选择画面；见下面的设备表。

这不是一个“勉强能跑”的技术演示。它是一个为日常游玩打磨的移动版，从你第一个角色一直到游戏后期全程可用。

平台：iPhone / iPad（iOS 26 及更新；iOS 18 – 25 用旧 API 构建）· Mac（Apple 芯片，macOS 26 或更新；macOS 15 – 25 用旧 API 构建）· Apple TV 4K（第三代，A15；社区移植版，开发者预览）· 游戏版本：带术士君临的 Switch 版，1.0.34.0（对应 PC 版 3.3.94012）· 英语 / 中文 / Español / Русский · 许可证：MIT · **自带游戏文件**

## 它是什么，不是什么

**它是：**

- 游戏自己的 aarch64 程序，**直接在设备上执行**，没有模拟 CPU。iPhone 和 Switch 使用同一类处理器；只有少数几条在 Apple 内核下无法原样执行的指令被重写，程序其余每个字节都保持原样发货。每个职业、每条符文之语、恐怖地带、Boss、掉落规则和任务流程都与原作完全一致。
- 游戏期望的平台服务——系统调用、文件系统、图形 API、音频、输入——由一个为 Apple 平台编写的小型宿主提供。图形 API 完全用 Apple 的 Metal 重新实现，中间没有模拟层，着色器从游戏原作离线翻译。
- 一个为手机打造的移植，并做到了极致：完整的触控方案、无边框 iPhone 和真正的全屏 iPad 显示、手柄支持、省电模式、存档同步、中英文，以及原作从未有的一整套后期模式和生活质量功能。

**它不是：**

- 模拟器、云游戏或串流。
- **游戏内容来源。它不含也不分发任何内容。** 本仓库没有游戏程序、美术、文本、数据表或着色器；所有这些都是在你自己的机器上从你自己的文件生成的（见 [docs/GAME_FILES.md](docs/GAME_FILES.md)）。仓库带的是我们记录下来的使移植生效的接口信息——着色器接口描述、图形 API 函数表、程序内地址等——在 [docs/DERIVED.md](docs/DERIVED.md) 中逐项列出。
- 在线。没有多人游戏；游戏完全离线运行，无需在线账号。

## 久经考验

封闭测试中全部 **44** 台 iPhone 和 iPad——35 台注册直装的设备（25 台 iPhone 和 10 台 iPad），外加 9 个各带一台设备的 TestFlight 账号——**用多个角色完成了普通、噩梦和地狱**，体验极佳。从 6 GB 内存的 iPhone 14 Pro Max 到最新的 iPad Pro，没有一台设备掉队。测试过的最低型号为 **iPhone 14 Pro Max（A16，6 GB）：完美的 60 fps**。iPhone 和 iPad 共享一个安装包。

## 快速、流畅、省电

在真实设备（iPhone 17 Pro Max）上测得：游戏内帧率 **60 fps** 稳定不掉帧；应用启动 0.15 s；到主菜单约 1 s；从主菜单进入游戏**约 1 s**；快速重启回到游戏约 1.2 s；换幕最长帧约 0.1 s；60 fps 全机功耗**约 3.8 W**（营地，50% 亮度）：满电可持续游玩近 5 小时；30 fps 省电模式**约 1.85 W**，约为 60 fps 的一半，续航约两倍。

安装包仅 100 MB 出头。游戏资源（约 5.6 GB）单独放到手机，更新应用不会碰到你的存档或资源。

为什么这么快：程序原生执行，没有一条指令经过模拟；图形直连 Metal；每个着色器都离线翻译并提前编译，进入新场景时无需编译。较老芯片（A16 及更早，如 iPhone 14 系列和 iPhone 15）不支持游戏原始的压缩纹理格式；它们需要从你自己的游戏文件制作额外的纹理包，然后也能跑满帧率——见 [docs/LEGACY_DEVICES.md](docs/LEGACY_DEVICES.md)。

## 为手指重新设计

这不是把手柄贴到屏幕上。每个面板和每个动作都在一个设计原则下为手指重建：**保持原始界面语言，用手势而不是往屏幕上加按钮**。文字大小和点击目标按手指尺寸设计。你拿起就会玩，长时间游玩也舒适。

- **移动**：带精确对角线的虚拟摇杆；点击 NPC 或地面可自动寻路；门、传送门和洞穴入口整面可点。
- **战斗**：按技能按钮施放，按住持续施放，**拖动以任意角度瞄准**；附近怪物自动锁定。两套技能。副武器技能一键施放——游戏自动换武器、施放、换回——按钮显示剩余充能。
- **Boss 血条**：固定在屏幕顶部，显示剩余百分比。
- **物品**：点击、双击、长按和拖放都跟手。双击装备可装备/卸下；把物品拖到商人面板任意处出售；堆叠上双击取 1、长按取 3；长按空格子整理。
- **文字**：用系统键盘输入。角色名可以是中文；留空则随机生成。
- **屏幕**：iPhone 上 19.5:9 屏幕无边填充，避开刘海和圆角；iPad 上游戏铺满整个屏幕，打开面板时界面自动居中；3D 画面可调亮。

### 手柄

连接手柄并按下任意键：界面切换为原始手柄布局，每个面板底部显示按键提示。触屏立即切回触控界面。物品栏、仓库、技能树、编年史和设置都可用手柄完全导航，按键映射与 Switch 一致。

## 在原作之上的新玩法

通关原作只是开始。在不改动原始规则的前提下，我们加入了一整套让你持续刷刷刷的后期内容。

### 大秘境

地狱通关后从哈洛加斯的红门进入。共 100 层，怪物逐层变强；在 15 分钟内填满进度条并击杀秘境守卫即可通关。每通关 2 层 +1 技能点 +5 属性点，技能等级上限从 20 提到 40。每 10 层有首通奖励，通关 10 层为佣兵解锁 6 个新装备槽。

### 后期 Boss Rush、极乐世界模式和击杀榜

- **后期 Boss Rush**：地狱通关后解锁，共 12 关；第 11 关是暗黑破坏神克隆体，第 12 关是三大 Uber Boss。
- **极乐世界模式**（建角色时选择）：独特 ×5、套装 ×3、符文 ×5；“不掉落”几率降到十分之一，Boss 每次击杀都像首杀一样掉落。
- **击杀榜**：每个 Boss 的击杀数、首杀时间、掉落的独特和套装物品数，以及最佳和平均击杀时间。

### 存储：收藏家的乐园

- **编年史仓库**：每件已鉴定的独特和套装物品有固定槽位，全角色共享，可搜索，可存取；“存入”按钮一键把背包和赫拉迪克方块中的独特、套装物品存入。
- **仓库**：扩宽到 14 列，5 页个人 + 5 页共享。
- **藏宝阁**：宝石、符文和材料页合并为一页，中间是赫拉迪克方块的合成格，找东西和合成不再翻页。
- **荷包**：扩展背包。野外拾得的符文和宝石自动放入，不占背包空间。

### 英语、中文、西班牙语和俄语

## 工作原理

程序重写器（`dm/tools/patch_nso.py`）只重写少数几条无法在 Apple 内核下原样运行的指令（线程指针寄存器、系统调用、定时器），其余逐字节保持原样；宿主（`dm/host`）加载重写后的程序并提供它调用的平台服务；图形层（`dm/gfx`）在 Metal 上实现游戏图形 API，着色器从原作离线翻译；iOS 应用（`dm/ios`）是外壳、触控和界面；验证（`dm/verify`）检查重写后的代码与原作行为完全一致，加上每次改动都要通过的回归门。

**为什么可以信任它：** 稳定性不是运气。测试和验证工具是项目的一部分——宿主和图形层的单元测试、每条重写指令的等价性检查、触控界面的脚本化通关回归，以及设备冒烟测试。

## 支持哪些设备

最低：**A14 / M1 芯片或更新**——图形层需要 Metal 3，Apple 从 A14 / M1 起支持。

|---|---|---|---|
| **iPhone / iPad，A17 Pro 及更新** | 是 | iOS 26 或更新：默认外壳/默认构建；iOS 18 – 25：iOS 18 外壳/旧 API 构建 | 主力设备，日常游玩 |

## 开始使用

两条路径都从**你购买的游戏文件**开始：Switch 版的《暗黑破坏神 II：狱火重生》加术士君临资料片，更新到 1.0.34.0。准备工作见 [docs/GAME_FILES.md](docs/GAME_FILES.md)。

> 本项目只提供工具和一个不含游戏内容的外壳。我们不分发、不背书、也不对任何第三方分发游戏资源、游戏可执行文件或含游戏内容的安装包负责。请只使用你合法拥有的游戏文件。

| | 有 Mac | 无 Mac |
|---|---|---|
| 电脑 | 装了 Xcode 的 Apple 芯片 Mac | Windows / Linux / 没有 Xcode 的 Mac |
| 方式 | 从源码完整构建 | 下载不含游戏内容的“外壳”，用打包工具加入你自己的游戏内容，再用侧载工具安装 |
| 说明 | 下面三步 | [docs/NO_XCODE.md](docs/NO_XCODE.md) |

签名用的 Apple 账号：付费开发者账号给你全部功能；免费 Apple ID 也行（无 iCloud 存档同步，且应用需每 7 天重新签名重装）。依赖完整清单见 [docs/DEPENDENCIES.md](docs/DEPENDENCIES.md)。

### 有 Mac：三步

1. 把游戏文件放进工作区（默认 `~/dm-work`，或设置 `DM_ROOT`）。
2. 准备工作区（`./setup.sh`）：检查工具、重写游戏程序、把游戏着色器翻译到 Metal。首次运行较久。
3. 填写签名信息并构建应用（`cp dm/ios/local.env.example dm/ios/local.env`，设置 `DM_TEAM_ID` 和 `DM_BUNDLE_ID`；免费 Apple ID 还需 `DM_FREE_ACCOUNT=1` 和 `DM_IOS_UDID`；然后 `cd dm/ios && ./run.sh build`）。

首次在手机打开应用时，它会要求“游戏资源文件夹”——你游戏文件中的 18 个资源归档。`./setup.sh check` 是健康检查。

### 直接在 Mac 上玩

同样 `./setup.sh` 后，再一条命令即可构建原生 macOS App（`source ~/dm-work/build/cache/dm/venv/bin/activate && dm/tools/mac_app.sh`），双击启动，支持键盘、鼠标和手柄，无需开发者账号。

### 无 Mac：外壳 + 打包工具

从本仓库 [Releases 页面](https://github.com/jhaizhou-ops/d2r-mobile/releases)下载预构建的“外壳”包（不含游戏内容），加入你自己的游戏文件，在 Windows 或 Linux 上制作安装包，再用侧载工具签名安装。这条路径上，因为制作包的电脑没有 Apple 着色器编译器，手机**首次启动**会花约 7 分钟编译着色器（一次性，有进度条）。步骤和验证程度见 [docs/NO_XCODE.md](docs/NO_XCODE.md)。

## 贡献与反馈

- 遇到问题就开 Issue（有模板）；附上暂停菜单中“Share Diagnostics”导出的文件最有帮助。
- 对标记未验证的项，告诉我们成功与否。两个答案都有价值。
- 改代码：先让上面的测试入口通过。每次改动都必须通过回归门。

**把它带到其他平台：** 这种方法不限于 iPhone 和 iPad。Apple 芯片 Mac 已有原生版，Apple TV 有社区移植版。Android 手机使用同类处理器，游戏程序也能原生执行，路径完全开放：只需替换宿主和图形层面向平台的部分。作者手边没有 Android 手机，很希望有人把它带到 Android。

**把它带到其他游戏：** 已经有人在同一宿主上试过其他 Switch 游戏。宿主有些默认为 iOS 打开且为这个游戏写的默认行为，换别的游戏会先撞上这些，开始前先关掉或移走（见原 README 列出的 `dm/host/*.c` 文件）。更干净的安排是把这些默认行为移到按游戏配置，让宿主保持无游戏特定默认值；欢迎朝这个方向的拉取请求。
